# Contributing

Thanks for helping keep this free API directory accurate and practical.

## Add or update an API

1. Read the provider’s official API documentation and its pricing, rate-limit, and acceptable-use pages.
2. Edit `docs/data/apis.json`. Keep the existing field names and JSON formatting.
3. Use a short, factual description. Set `authentication` to `No`, `Optional`, or `Yes`; use `Optional` when public access exists but keys unlock higher limits or some endpoints.
4. Set `checked_on` to the date you checked the provider’s current terms, in `YYYY-MM-DD` format.
5. Include the canonical docs URL and a pricing/limits/policy URL. If a policy is not published separately, link to the docs and say so in the pull request.
6. Explain the evidence for no-cost access in your pull request.

## Quality bar

- No referral links, affiliate links, spam, or SEO keyword stuffing.
- Do not call an API “unlimited,” “permanently free,” or “commercially free” unless the provider explicitly supports that exact claim.
- Distinguish open data, free access, and a free tier. Record sign-up, key, quota, attribution, and non-commercial restrictions where known.
- Do not submit services that are effectively trials requiring payment details, or endpoints that violate a provider’s terms.
- Prefer official provider sources. Do not copy another directory wholesale.
- Keep entries alphabetized within categories when practical; avoid duplicates.

## Report an issue

Please include the API name, the relevant official policy or documentation URL, what changed, and the date you checked it. Avoid posting API keys or personal data.
